# Truckfire

Truckfire is a road-transport simulator project built from scratch in Godot 4.7.

## Prototype 0.1
Open this folder with Godot 4.7 and run the project. See [docs/PROTOTYPE_0.1.md](docs/PROTOTYPE_0.1.md) for controls and current scope.

The prototype uses the supplied Mercedes GLB and CityStreetAsphaltGenericClean001 PBR textures.

## Repository assets
The complete downloadable prototype package includes the imported GLB and the PBR texture maps. Binary source assets are not duplicated in this source-only Git branch; use the complete Truckfire_v0.1.zip package when opening the project locally.
